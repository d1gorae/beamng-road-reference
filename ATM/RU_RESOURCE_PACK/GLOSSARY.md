# Глоссарий ATM10 RU

Термины используются единообразно во всех модах. Если конкретный мод использует устоявшийся русский термин, он может быть уточнён с фиксацией здесь.

| English | Русский | Примечание |
|---|---|---|
| ME Network | МЭ-сеть | Термин Applied Energistics 2 |
| ME Storage Cell | МЭ-ячейка хранения | Не «клетка» |
| Chemical Storage Cell | химическая МЭ-ячейка хранения | Applied Mekanistics |
| Portable Cell | портативная ячейка | Сохранять тип ресурса в названии |
| P2P Tunnel | P2P-туннель | P2P не переводить |
| Node | узел | В контексте визуализации сети |
| Link | соединение | В контексте визуализации сети |
| Dense | плотный | Тип узла/соединения |
| Tick | тик | Единица игрового времени |
| Profiler | профилировщик | Инструмент измерения производительности |
| Whitelist | белый список | Настройки разрешённых элементов |
| Blacklist | чёрный список | Настройки запрещённых элементов |
| Shift | SHIFT | Название клавиши |
| QIO | QIO | Технический термин Mekanism |
| Chemical | химические вещества | Не переводить как «химикаты» без контекста |
